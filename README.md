## Descrição

Gestão à Vista é uma suíte de aplicações projetada para facilitar o gerenciamento visual de processos, métricas e indicadores em ambientes corporativos. O objetivo é fornecer ferramentas intuitivas para monitoramento em tempo real, permitindo que equipes visualizem dados de forma clara e acessível em diferentes dispositivos.

As aplicações permitidas incluem:
- **Protetor de tela para PC**: Uma tela de descanso personalizável que exibe dashboards e métricas enquanto o computador está inativo.
- **Aplicação de visualização para TVs**: Uma interface otimizada para telas grandes, ideal para exibição em salas de reunião ou áreas comuns, mostrando atualizações em tempo real.
- **Aplicação web de gestão**: Uma plataforma online completa para configuração, gerenciamento e análise de dados, acessível via navegador.

O projeto é construído com tecnologias modernas, priorizando usabilidade, segurança e escalabilidade. Alguns recursos avançados são pagos para suportar o desenvolvimento contínuo e oferecer funcionalidades premium.

## Recursos

### Recursos Gratuitos
- Visualização básica de dashboards em todos os aplicativos.
- Integração com fontes de dados simples (ex.: CSV, JSON).
- Configurações personalizadas de layout e cores.
- Suporte para múltiplos idiomas (incluindo português).

### Recursos Pagos
- Alertas em tempo real via e-mail ou notificações push.
- Relatórios analíticos detalhados e exportação de dados.
- Suporte prioritário e atualizações exclusivas.
- Customizações empresariais, como branding personalizado e hospedagem dedicada.

Para acessar os recursos pagos, adquira uma licença premium através do nosso site ou entre em contato conosco.

text2. Instale as dependências (requer Node.js e Python instalados):

Baixe no bin o instalador
